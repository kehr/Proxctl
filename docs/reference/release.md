# Release Process

Release versions are managed by the root `VERSION` file.

## Create a release

```bash
cat VERSION
git tag v0.2.0
git push origin v0.2.0
```

The release workflow refuses tags that do not match `VERSION`.

## Release workflow

On a version tag, GitHub Actions:

1. checks out the repository
2. sets up Go
3. validates tag and `VERSION`
4. runs tests
5. runs `go vet`
6. builds release archives
7. generates structured release notes
8. uploads assets to GitHub Releases

## Release notes

Release notes are generated by:

```bash
./scripts/release-notes.sh v0.2.0
```
